    Setup — only you can see this

    This panel disappears the moment you fill in data.js. Nobody else sees it once you do.

    1. Drop photos into the photos/ folder next to this page.
    2. Open data.js and replace the four sample moments with real ones — one per photo, oldest first.
    3. Commit and push. The page updates in about a minute.

    Shortcut: run ./add-photos.sh ~/Desktop/jane-photos from this folder — it resizes everything and prints the moments entries ready to paste.
